# Развёртывание NEXUS Arena (без демо-режима)

В отличие от старой статической демонстрации, это клиент-серверное приложение. Аккаунты, чаты, кланы и матчи хранятся на сервере и доступны всем пользователям одного развёртывания.

## 1. Локальная проверка

Установить Python 3.12+ → `pip install -r server/requirements.txt` → задать `ADMIN_EMAIL`, `ADMIN_PASSWORD` (не меньше 12 символов) → `python -m uvicorn server.app:app --host 127.0.0.1 --port 8000`. Адрес: http://127.0.0.1:8000. Это доступно только вашему ПК.

## 2. Домен и сервер

Нужен сервер/VPS с Docker и публичный домен. Направить DNS A/AAAA запись домена на IP сервера. Скопировать `server/.env.example` в `.env` в корне проекта, выставить:

```text
DOMAIN=arena.example.com
PUBLIC_ORIGIN=https://arena.example.com
COOKIE_SECURE=1
ADMIN_EMAIL=your-email@example.com
ADMIN_PASSWORD=YOUR_OWN_LONG_RANDOM_PASSWORD
ADMIN_NICK=NEXUS_OWNER
```

Далее `docker compose up -d --build`. Caddy автоматически запросит TLS-сертификат при правильной DNS/открытых 80,443. **Не размещайте .env, SQLite-файл и резервные копии в общедоступной web-папке или Git.**

## 3. Проверить на двух устройствах

Открыть `https://arena.example.com`, зарегистрировать аккаунт игрока A и B, создать клан A, подать заявку B, одобрить A, обменяться сообщениями с разных телефонов/браузеров. Для лобби отправить приглашение по нику, принять его на втором аккаунте.

Чтобы сформировать полноценный матч 5×5, нужны 10 реальных аккаунтов в очередях; сервер не добавляет ботов. Соединение с MLBB отсутствует: матч нужно проводить в самой игре.

## 4. Разработчик

Первый администратор создаётся сервером при старте по `ADMIN_EMAIL` и `ADMIN_PASSWORD`. Любой обычный пользователь регистрируется без прав администратора. Сервер проверяет роль в каждом административном API. Не публикуйте секреты и пароль разработчика внутри мобильного приложения. Для смены админ-пароля в текущей версии потребуется отдельная миграция/инструмент администратора: изменение переменной окружения **не** изменит существующий пароль. Поэтому сохраните реквизиты надёжно.

## 5. Данные и безопасность

SQLite работает в однопроцессной конфигурации. Для высокой нагрузки понадобится PostgreSQL, фоновые задачи и WebSocket. Настройте резервное копирование `./data/arena.sqlite3` методом SQLite backup API / остановки сервиса, проверяйте восстановление. Для публичного запуска обязательны контроль злоупотреблений, почтовое подтверждение и восстановление доступа, удаление устаревших сессий и уведомления о нарушениях. Направляйте сообщения пользователей только через HTTPS.

Политика конфиденциальности и правила находятся в `web/privacy.html` и `web/terms.html`; заполните реальные юридические данные оператора и контакты перед запуском. Удаление профиля доступно из ⚙ и на `https://ДОМЕН/account-deletion`.

**Ни игра MLBB, ни официальный турнирный оператор не подключены автоматически.** Призовой фонд лишь объявляется организатором, платёжной системы нет. Проводите только бесплатные турниры, соответствующие правилам игры и законам вашей страны.

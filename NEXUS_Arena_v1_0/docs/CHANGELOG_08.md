# NEXUS Arena — изменения 0.8

- Капитаны обеих команд прикладывают отдельные скриншоты результата.
- Совпавшие отчёты больше не завершают матч автоматически.
- Матч переходит в «Проверка модератором», либо «Спор» при расхождении отчётов.
- Утверждение победителя и проигравшего — только серверной ролью администратора матчей или разработчика и только после 2 изображений.
- ELO +25/−25, победы/поражения и счётчик калибровочных матчей обновляются только после утверждения.
- Доступные только участникам и администрации изображения сохраняются на сервере в SQLite в формате JPEG.
- Отдельная роль администратора матчей, назначаемая исключительно разработчиком.
- Ввод K/D/A для каждого участника матча, журнал изменений и суммарная статистика в профиле и лидерборде.
- Отмена спорного или незавершённого матча с причиной, без изменения ELO.
- Адаптивный интерфейс ПК/Android WebView, выбор скриншота через мобильную галерею.
- Автоматическая миграция существующих баз SQLite при запуске.

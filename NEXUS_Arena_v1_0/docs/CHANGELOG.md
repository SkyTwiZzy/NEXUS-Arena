# Изменения NEXUS Arena

## 0.7 — готовность 10/10, аватарки, поддержка и управление матчами

- Готовность всех игроков найденного матча: счётчик, тайм-аут 90 секунд, отказ без изменения ELO.
- Назначенный создатель комнаты MLBB: ник, Player ID и Server ID.
- Аватары JPG/PNG/WebP: серверная валидация, повторное кодирование, удаление.
- Отзывы 1–5, баг-репорты и личная поддержка с сохранением данных в SQLite.
- Панель разработчика: ответ/статус, публичные отзывы, отмена незавершённых матчей.
- Информационная страница развития проекта, без приёма платежей.
- Android WebView: системный выбор аватарки.

# NEXUS Arena 0.6 — 2026-10-15

- Организатор турнира и разработчик могут редактировать данные турнира через API и интерфейс.
- Время начала, срок закрытия регистрации и явный UTC-offset.
- Ручное закрытие/открытие набора, серверные проверки прав и лимитов.
- Закрытые турниры остаются видимыми.
- Автоматический запрет регистрации после указанного срока.
- Калибровка ранга на 10 подтверждённых матчей; ELO скрыт до завершения.
- Общий интерфейс для адаптивного веб-сайта и Android Flutter WebView.
- BUILD_ANDROID_APK.bat и установка иконок без Pillow.
- Сохранена миграция прежней SQLite-базы.

**Важно:** APK/AAB не скомпилирован в данной среде; исходный код Android включён.

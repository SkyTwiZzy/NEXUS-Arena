# NEXUS Arena 1.1 — PUBLIC WEB

Версия 1.1 обновляет NEXUS Arena 1.0 для **общего доступа через интернет**. Функции игры не потеряны: 1×1, 2×2, 5×5, ELO и ранги, кланы и чат, турниры, готовность, ручная проверка скриншотов, K/D, аватарки, роли и поддержка.

## Как сделать сайт общедоступным

### Быстрый временный адрес с Windows

1. Установите Python и `cloudflared` (см. `docs/PUBLIC_LAUNCH_RU.md`).
2. Один раз настройте аккаунт владельца с помощью `SETUP_OWNER_AND_START.bat`, затем закройте сервер.
3. Запустите **`START_NEXUS_PUBLIC_SERVER.bat`**.
4. Отдельно запустите **`START_PUBLIC_LINK.bat`**.
5. Используйте появившуюся HTTPS-ссылку `https://...trycloudflare.com` с другого устройства. Два окна должны оставаться открытыми.

### Постоянный сайт, который не зависит от домашнего ПК

Вариант **Render**: добавлен `render.yaml` с Docker-сервисом и постоянным диском `/data`. Для такого варианта нужен **платный** тариф с диском; настройка осуществляется через GitHub + Render (инструкции внутри).

Вариант **VPS**: `docker compose up -d --build` с `Caddyfile`, доменом, DNS и HTTPS. База сохраняется в `./data/arena.sqlite3`.

📖 **Подробная инструкция на русском: [`docs/PUBLIC_LAUNCH_RU.md`](docs/PUBLIC_LAUNCH_RU.md)**

## Безопасность

- Публичный доступ защищён HTTPS и secure cookie. Не отправляйте пароли и не добавляйте `.env`/базу данных в публичный репозиторий.
- Перед общим доступом смените ранее отправленный в переписке пароль владельца.
- Для большого публичного запуска необходимы проверка email, восстановление паролей, модерация и тестирование нагрузки.
- **Сайт сам по себе не был опубликован на хостинге**: архив даёт код и средства размещения; реальный адрес появится после вашего запуска туннеля или деплоя.

## Android

Мобильный WebView-клиент подключается к **реальному HTTPS-адресу**. Укажите его в `BUILD_ANDROID_APK.bat` (или GitHub Actions / `--dart-define=ARENA_URL=...`) при сборке. Временный trycloudflare URL не подходит для публикации APK: после перезапуска он изменится.

### Копия данных на Windows

Запусти `BACKUP_ACCOUNTS.bat`: в папке `backups` появится резервная копия SQLite. Храни её приватно.
